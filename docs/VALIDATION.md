## What the local checks do not establish

The integration bridge is test infrastructure, not a replacement production API. It executes real SQL/RLS but synthesizes test authentication and a small REST transport. Real Supabase JWT validation, invitation email/SMTP, callback expiry, Storage MIME/size handling and signed URL expiry, PostgREST query behavior, concurrent hosted database sessions, Vercel domain/refresh behavior and physical-phone geolocation still require a separate staging project. The Edge Function has been implemented but not deployed or verified against hosted Auth. Physical iPhone/WebKit and Android devices were not tested. Search, route plotting and approval widgets are connected in application code; no demo dataset is bundled in the production frontend.

Apply and verify the staging configuration and acceptance gate in [MIGRATION.md](MIGRATION.md) before any production cutover. Laravel dependencies remain deliberately installed until those checks pass. Native background tracking/offline storage are not implemented; [MOBILE_API.md](MOBILE_API.md) describes the supported delayed location contract and future Expo requirements.
